==============================
 주제 카드  (6교시)
==============================
팀 / 이름 : 김정은, 김석진
프로젝트  :  카페 주문/매출    난이도: ★★
한 문장   :  카페 사장님이 일일 매출 통계를 확인 할 수 있는 프로그램
필수 기능 : ① 메뉴 주문  ② 영수증 출력  ③ 일일 매출 집계
쓸 개념   : 딕셔너리 / JSON / FILE

[1분 발표]
"저희 팀은 ○○ 프로그램을 만듭니다.
 이 프로그램은 ~할 수 있는 프로그램입니다.
 필수 기능은 ①②③④입니다."

고객에게 메뉴명, 사이즈, 수량, 샷 수, 아이스/핫 여부가 포함된 주문정보를 받아
결제 수단과 결제 시간이 포함된 영수증을 출력하고
마감 후 하루 매출 통계를 확인할 수 있는 프로그램입니다.
필수 기능은 메뉴 주문, 영수증 출력, 일일 매출 집계 확인 입니다.
시간이 되면 주문 정보에 상세 커스텀 부분을 추가해 재료 재고 확인 등을 도전해볼 생각입니다.
